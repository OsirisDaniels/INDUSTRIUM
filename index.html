Production chains

Basic: Ore deposit → Drill → Furnace → Metal → Sell

Logistics: Drill → Conveyor → Storage → Sell

Tier 2: Drill → Crusher → Furnace → Sell

Sandworks: Sand + water → wet sand → Separator → gold + residue → Storage.

Waste recycling: Residue → Thermal Kiln → burnt residue → Compression Press → more gold.

Fluid control: Pumps redirect water and coolers freeze nearby pools. Use stone to make basins.

World events: Optional rain, earthquakes and geothermal steam. Turn these on or off in Manage.
